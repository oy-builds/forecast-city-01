# forecast-city-01

Entry for the make.fun bounty **Funniest Forecast for a City That Isn't**
([bounty page](https://make.fun/bounty/u-eager-stork-81-9647-funniest-forecast-for-a-city-2a8769cf)).

`main.ts` (Node 22, zero dependencies) writes a single line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): a weather
bulletin for the invented city of Gloomhaven, where the forecast is
overcast with a 90% chance of rain — and the sun only ever shows up to
apologize. The program validates the house gate before writing: UTF-8
text, 1–120 characters, a single line, not only whitespace.

Run it:

```sh
node main.ts
```
